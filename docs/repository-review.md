# Repository review

Reviewed 84 repository folders. The catalog contains 61 entries drawn from 72 folders; related implementations share a project entry.

The review used root READMEs, dependency manifests, and targeted source files. It is a content inventory, not a code audit of every implementation. Project descriptions summarize repository behavior; they do not imply sole authorship or independently verified customer outcomes.

Organization and client project names, identifying source-folder labels, and project links have been generalized. Source labels below are descriptive aliases where needed, not filesystem paths. Employer attribution and third-party technology names remain.

## Corrections and grouping decisions

- bunx-ray reflects the current directory heat-map tool, replacing the earlier bundle-analysis description.
- Long-Tail Keyword Automation uses SQLite in the reviewed implementation.
- aiseo-audit, bunx-ray, Fathom, Harvest, and XML package versions come from their local manifests.
- Stats on Github uses JavaScript and Chart.js; it is not labeled as React.
- HubSpot Integration Prototype exposes Express HTTP routes. The folder name does not establish an implemented MCP server.
- alignguard is marked as an experiment. Its Python extraction modules are implemented; the TypeScript entry point only exports a version.
- Duplicate daily-snapshot checkouts share one entry.
- Company website generations, related Google connectors, and product documentation are grouped with their main project.
- Sales demos use a general description without copying client requirements, private links, or datasets.
- Earlier unsupported numeric impact, scale, store availability, and release-date claims were removed from project copy.
- New internal project cards do not invent GitHub URLs or public deployments. Links that identify generalized projects have been removed. Remaining public-tool links were not checked for live availability.
- No source instructions to deploy, send messages, install services, or mutate neighboring projects were executed.

## Content boundaries

Only descriptive project content and the existing Geist font assets were brought into the site. Credentials, personal finance records, contact exports, operational IDs, client materials, and private screenshots are not included. The source repositories and existing résumé artifacts were not modified.
